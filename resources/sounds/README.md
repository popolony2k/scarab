# resources/sounds/

Shared audio assets — part of `resources/` at the repo root, the general-purpose shared-resources area shipped with Scarab itself (see the root [README.md](../../README.md)), free for this repo's own samples *and* for any community game built on Scarab to use.

`stage_theme.wav` — a real, plain WAV (16-bit PCM, mono, 22050 Hz), copied unmodified from [sunlight](https://github.com/popolony2k/sunlight)'s own [`scriptprocessor` sample](https://github.com/popolony2k/sunlight/tree/main/samples/scriptprocessor) — shared here since both repos are owned/authored by the same project, the same rationale as [resources/tilemap/](../tilemap/README.md)/[resources/sprites/](../sprites/README.md).

Used in [samples/sound](../../samples/sound/docs/README.md) to demonstrate every direct/queued sound and song primitive.
